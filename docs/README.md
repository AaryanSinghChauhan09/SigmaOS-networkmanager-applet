# SigmaOS-networkmanager-applet — Documentation

## Purpose

SigmaOS networkmanager-applet component inspired by Linux Mint / Omarchy / Arch Linux.

## Architecture

- `src/lib.rs` — public API (registry archetype)
- `tests/` — integration tests
- Mechanism here; policy lives in configuration.

## Principles applied

Abstraction, loose coupling, high cohesion, KISS, DRY, secure defaults,
fail-fast, defensive programming, deterministic testing.
